# Bari Launcher

A simple and beautiful Minecraft launcher made with **Python** and **Turtle** graphics.

![Bari Launcher](https://via.placeholder.com/800x400?text=Bari+Launcher)

## ✨ Features

- Clean and colorful GUI using Python Turtle
- Easy to use interface
- Minecraft version selector
- Custom username support
- Simple and lightweight
- No external heavy dependencies

## 📸 note: i made this for linux only i did not look at how this works on windows maybe you will need a little modifications for windows/mac

## 🛠️ Requirements

- Python 3.8 or higher
- `turtle` (built-in)
- `minecraft_launcher_lib` (for downloading Minecraft files)

## 🚀 Installation

just run the python file
